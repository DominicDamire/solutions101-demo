Solutions101 — working prototypes

Solutions101 — студия автоматизации бизнес-процессов. Здесь четыре рабочих прототипов: каждый — отдельное приложение в одном HTML-файле, без сервера и установки, его можно открыть, понажимать и сломать. Прототипы работают на демо-данных: все компании, товары, суммы и имена в них выдуманы.

Solutions101 is a business-process automation studio. Below are four working prototypes, each a single HTML file with no backend that you can open and click through. They run on demo data: every company, product, amount and name in them is invented.

Прототипы Prototypes

4 · demo data

  • Equipment-rental fleet

    Арендный парк

    Календарь занятости, договоры, смены, платежи и доходность каждой машины.

    Occupancy calendar, contracts, shifts, payments and profitability of each machine.

    Open demo → Code ↗

  • Warehouse scanner (WMS)

    Складской терминал

    Экран сборщика и офисный режим: отбор по FEFO, приёмка, размещение, слепая инвентаризация.

    Picker terminal and office view: FEFO picking, receiving, putaway, blind stock count.

    Open demo → Code ↗

  • Counterparty settlements

    Взаиморасчёты с контрагентами

    Чистая позиция по каждому контрагенту, возраст долга, платёжный календарь и акт сверки.

    Net position per customer and supplier, debt ageing, payment calendar, printable reconciliation act.

    Open demo → Code ↗

  • Auto-parts store

    Магазин автозапчастей

    Подбор по VIN или по марке и модели, каталог с фильтрами, карточка детали и заказ через корзину.

    Find parts by VIN or by make and model, filter the catalogue, order through a cart.

    Open demo → Code ↗
